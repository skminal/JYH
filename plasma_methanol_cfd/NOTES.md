# 甲醇中针电极放电：针尖气相来源的数值实验 — 工作笔记

目标问题：甲醇中针电极放电时，针尖处的气相是焦耳热把液体烧开产生的，还是放电本身产生的？起始判据是什么？
工况点：DC 2.6 kV。参考文献：Wang et al., *Matter* 7 (2024) 3024–3035（下称 W24）。

## 1. 求解器与环境

- 选用 **Gerris**（Popinet，snapshot 131206，Basilisk 的前身）+ 其 `electrohydro` 模块（López-Herrera, Popinet & Herrada, JCP 2011）。
  理由：轴对称 VOF + 四叉树自适应 + 漏电介质/欧姆传导在同一程序里，且有公开验证。
  Basilisk 官网在本环境不可达；apt 里的 Gerris 包不含 electrohydro 模块，所以从 Ubuntu 源码包自行编译（`--disable-mpi`）。
- 对源码做了两处补丁（均在 `case/*.patch`）：
  1. `electrohydro.c`：Maxwell 应力项原本不支持绝缘（零法向通量）固壁，补上该分支。（基线算例最终未启用电场体积力，见 §4。）
  2. `timestep.c`：压力方程的体积源（`Source P`）在轴对称/切割单元里漏乘单元分数，导致 div u ≠ 源项。修正后验证通过（§3）。
- 另一个踩到的坑：该版本的隐式电荷弛豫只有在 `L = 1`（盒子边长为单位长度）时稳定，所以全部按盒长无量纲化。
- 文献文件夹（针-环/针-针放电视频）在仓库任何分支上都没有找到，本工作未使用这些视频。

## 2. 工况（本算例）

| 项目 | W24 实验 | 本算例 |
|---|---|---|
| 液体 | 无水乙醇 200 mL（μ=1.17 mPa·s，ρ=791 kg/m³，σ=22.14 mN/m，εr=24.3） | 甲醇 25 °C：ρ=786.6 kg/m³，μ=0.544 mPa·s，σ=22.07 mN/m，εr=32.66，cp=2530 J/kg/K，k=0.200 W/m/K，Tsat=64.7 °C，hfg=1.10 MJ/kg |
| 液体电导率 | 未给 | 44 µS/m（基线；文献值 7–44 µS/m，高纯可低两个量级——**需实测**） |
| 高压电极 | 石英管 ID 0.3/OD 0.5 mm 内套钨针 Ø0.08 mm，针尖与管口平齐 | 钨针：尖端半径 0.04 mm，锥半角 15°，杆 Ø0.5 mm；无石英管 |
| 对电极 | 不锈钢环 ID 20 mm、线径 2 mm，距针尖 30 mm | 相同 |
| 电压 | DC 0–2.8 kV（电源 0–30 kV，0–2 mA） | DC 2.6 kV |
| 通气 | He 3 mL/min | 无（气相只能原位产生） |
| 环境 | 常压室温 | 1 atm，25 °C |

去掉石英管的原因：细长绝缘死腔使该版本多重网格电势求解发散（逐项排查确认）；同时“无通气的针-环电极”正是要回答的问题对应的构型。

计算域：轴对称，r ≤ 12.9 mm，z ∈ [−3.17, 35.53] mm（3 个盒子），最细网格 12.6 µm（level 10，针尖半径上 3.2 格），针尖 0.3 mm 内静态加密，界面/温度梯度/涡量自适应。

## 4. 模型

- 两相不可压 N–S + VOF（PLIC）+ 表面张力 + 重力 + Boussinesq 热浮力。
- 电势：欧姆传导 ∂ρe/∂t = ∇·(K∇φ)，∇·(ε∇φ) = −ρe（隐式电荷弛豫，甲醇 ε/K = 6.6 µs）。针 φ = V，环 φ = 0。
- 液相能量：θ = (T−T0)/(Tsat−T0)，只存在于液相（VOF 浓度示踪），源项为焦耳热 K_l E²。
- 成核：针表面 80 µm 层内液体 θ ≥ 1.1（约 4 K 过热）处转为蒸气膜。
- 相变：界面格向饱和温度弛豫；过热→蒸发，过冷→冷凝（只冷凝可凝部分）。
- 放电闭合（**假设**）：气相电导率 K_g = K_p (E/E_c)^4（上限 10 K_p），E_c = 3 MV/m；
  气相放电功率全部用于产气（上限），其中 30% 用于 CH3OH → CO + 2H2（不可凝），其余蒸发（可凝）。
  K_p 是自由参数：0（放电关）、0.1 K_l（电晕型）、30 K_l（辉光型）。
- **未包含**：界面 Maxwell 应力/EHD 体积力。原因：单相液体里针尖 Maxwell 应力约 94 kPa，其离散误差驱动出 17 m/s 的伪射流；
  而本模型电导率均匀时真实体积力为零。去掉后速度降到 cm/s 量级的热对流。代价：气泡形貌不含电应力作用。
- 针体热边界：`run_*` 系列为绝热针（上限）；`prod_sink` 为等温散热针。
